## 实验任务

本周主题是把数值求解讲成两个概念：**递归**与**分治**。

- **递归**：单摆每一时刻的状态都由上一时刻递推得到，`θ(n+1) = f(θ(n), ω(n))`，程序里表现为函数自己调用自己、算到设定步数为止。
- **分治**：把长时间区间二分成若干子区间，各自递归求解后再把结果拼回整段曲线。

在递归与分治的基础上，用数值方法（如欧拉法或四阶龙格-库塔法）模拟单摆随时间变化的摆角，并与小角度近似解析解 `θ(t) = θ₀·cos(ωt)` 做对比。
